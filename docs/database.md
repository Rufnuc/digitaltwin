# Database

PostgreSQL, accessed via SQLAlchemy 2.0 (declarative `Mapped` models) and
migrated with Alembic. 25 domain tables + `alembic_version`.

## Mixins

- **TimestampMixin** — `created_at`, `updated_at` (timezone-aware).
- **ProvenanceMixin** — `data_origin`, `verification_status`, `confidence`,
  `extraction_method`, `source_reference`, `verified_by_id`, `verified_at`.
  Attached to imported/extracted business records so uncertain source data is
  never silently trusted (spec §11).

## Migrations

```bash
cd apps/api && . .venv/bin/activate
export DATABASE_URL="postgresql+psycopg://digitaltwin:digitaltwin@localhost:5432/digitaltwin"
alembic upgrade head           # apply
alembic revision --autogenerate -m "message"   # create new
alembic current                # show applied revision
```

The initial migration `alembic/versions/*_initial_schema.py` was autogenerated
against and applied to real Postgres.

## Money & numeric types

Money is `Numeric(16,2)`; quantities `Numeric(14,3)`. Summary/rollup columns
(e.g. `customers.lifetime_revenue`) are **nullable** so "not yet computed" is
distinct from zero.
